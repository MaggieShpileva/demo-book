# WakaTime: фиксация времени в Cursor

WakaTime автоматически считает время кодирования в редакторе. Вручную таймер включать не нужно.

## 1. Аккаунт и API-ключ

1. Зарегистроваться на [wakatime.com](https://wakatime.com).
2. Откройте [Settings → API Key](https://wakatime.com/settings/api-key).
3. Скопируйте ключ.

## 2. Установка плагина в Cursor

1. Установаить расширение WakaTime https://marketplace.cursorapi.com/items/?itemName=WakaTime.vscode-wakatime
2. Инструкция по установке https://wakatime.com/cursor
3. Вставить API Key в Cursor

## 3. Как это работает

- Пишете или правите файлы — время уходит в WakaTime.
- Статистика: [Dashboard](https://wakatime.com/dashboard) — проекты, языки, файлы, дни/недели.
- В статусной строке Cursor обычно видно сегодняшнее время (например, `2 hrs 15 mins`).

## 4. Проверка

1. Откройте любой файл в проекте и поработайте 2–5 минут.
2. Обновите [Dashboard](https://wakatime.com/dashboard).
3. Должны появиться проект (часто имя папки) и язык.

## 6. Замечания

- Считается активность в редакторе (набор, сохранение, переключение файлов), а не весь день за компьютером.
- В Cursor время иногда может отображаться как VS Code — известная особенность плагина; на общую сумму часов обычно не влияет.
- Локальный лог задач в `.cursor/task-time/` не связан с WakaTime: WakaTime — трекер по IDE, локальный лог — по чатам/задачам.
